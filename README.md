### Elreda Advertising — Official Website

موقع تعريفي احترافي **ثنائي اللغة** (عربي افتراضي / إنجليزي) لشركة **الرضا للدعاية والإعلان**.
مبني بـ HTML / CSS / JavaScript نقي — بدون أي إطار عمل أو خطوة بناء.

🔗 **الدومين:** https://www.elreda-ads.com

## ✨ المميزات

- **ثنائي اللغة بصفحات ثابتة منفصلة** — العربية على الجذر `/` والإنجليزية على `/en/`.
  كل لغة لها ملفات HTML كاملة بنصوص حقيقية، فمحركات البحث وروبوتات الذكاء الاصطناعي تقرأ المحتوى **بدون تشغيل JavaScript**.
- **خط Tajawal** للعربية و **Manrope** للإنجليزية، مع دعم كامل لاتجاه RTL / LTR.
- **أنيميشن قوي**: شاشة تحميل، مؤشر تقدّم القراءة، مؤشر ماوس مخصص، ظهور العناصر عند التمرير، عدّادات أرقام، شبكة جزيئات متحركة، تأثير الضوء على الكروت، وشريط متحرك.
- **5 صفحات لكل لغة**: الرئيسية · من نحن · الخدمات · أعمالنا · تواصل معنا (+ صفحة 404).
- **4 أعمدة خدمات**: التصميم · الطباعة · الويب · **الأنظمة المحاسبية والضريبية**.
- **نموذج طلب خدمة** يرسل البيانات مباشرة إلى واتساب برسالة منسّقة بلغة الزائر.
- **معرض أعمال** بفلاتر، Lightbox، وأوصاف مكتوبة تحت كل عمل.
- **متجاوب بالكامل**، يدعم `prefers-reduced-motion`، ورابط «تخطَّ إلى المحتوى» وتركيز واضح للوحة المفاتيح.

### لماذا هذا مهم لمحركات البحث الذكية
معظم روبوتات الذكاء الاصطناعي (GPTBot، PerplexityBot، CCBot وغيرها) **لا تشغّل JavaScript**.
لذلك كُتب المحتوى مباشرة في HTML لكل لغة بدل توليده بالجافاسكريبت — وهذا الفارق وحده هو ما يجعل الموقع مقروءًا بالكامل لهذه الأنظمة بدل أن يظهر لها فارغًا.

### ✅ خطوات مطلوبة منك بعد النشر
1. سجّل الموقع في **Google Search Console** وأرسل `sitemap.xml`.
2. سجّله في **Bing Webmaster Tools** (يغذّي ChatGPT Search و Copilot).
3. أنشئ **Google Business Profile** بنفس الاسم والعنوان والهاتف الموجودة في الموقع، وأضف رابط الموقع — هذا أقوى إشارة محلية.
4. أضف الإحداثيات الدقيقة لمقرّك من خرائط جوجل داخل `assets/js/` أو في الـ JSON-LD (حقل `geo`) — تُركت فارغة عمدًا حتى لا تُدخل بيانات غير دقيقة.
5. اجعل الاسم والعنوان والهاتف (NAP) متطابقين حرفيًا في كل مكان: الموقع، فيسبوك، إنستجرام، بيهانس، لينكدإن، خرائط جوجل.
6. راجع الأرقام في قسم الإحصائيات (250 مشروع / 120 عميل / 8 سنوات) وعدّلها للأرقام الحقيقية — الدقة تبني الثقة وتحمي من ادعاءات غير مدعومة.

### ملفات الشعار
| الملف | الاستخدام |
|---|---|
| `logo-mark.png` | الرمز الكوفي وحده (الهيدر، الهيرو، شاشة التحميل، الفافيكون) |
| `wordmark-dark.png` / `wordmark-light.png` | كلمة «للدعايا والإعلان» وحدها بنفس الخط الأصلي |
| `logo-dark.png` / `logo-light.png` | الشعار الكامل (رمز + كلمة) **بدون سطر الخدمات** — للفوتر وصفحة 404 وصورة المشاركة |

> الهيدر يستخدم الرمز والكلمة جنبًا إلى جنب (Horizontal lockup) لأن الشعار المكدّس يصبح غير مقروء داخل شريط بارتفاع 78 بكسل. نفس الرسم ونفس الخط — الترتيب فقط أفقي.

## 🌍 النشر

### Vercel (موصى به)
1. ارفع المشروع على GitHub.
2. من [vercel.com](https://vercel.com): **Add New → Project** واربط المستودع.

## ✏️ كيف تعدّل المحتوى

النصوص مكتوبة مباشرة داخل ملفات HTML لكل لغة (هذا مقصود لأجل السيو).

- **لتعديل نص عربي:** افتح الملف في الجذر (مثل `services.html`) وعدّل النص.
- **لتعديل نفس النص بالإنجليزي:** افتح `en/services.html` وعدّل ما يقابله.
- **رقم الواتساب:** في `assets/js/main.js` أول السطور (`WA_NUMBER`) وفي روابط `wa.me` داخل HTML.
- **الألوان:** أول `assets/css/style.css` تحت `:root`.
- **إضافة عمل جديد للمعرض:** ضع الصورة في `assets/img/work/` (نسخة كبيرة + نسخة `-thumb`)، وانسخ بلوك `<article class="work">` في `portfolio.html` و`en/portfolio.html`.
- **إضافة سؤال شائع:** أضفه في `index.html` داخل قسم `#faq` **وأضفه أيضًا** في كتلة JSON-LD أسفل الصفحة (`FAQPage`) حتى تتطابق البيانات المنظّمة مع المعروض.
