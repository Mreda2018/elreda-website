# الرضا للدعاية والإعلان — الموقع الرسمي
### Elreda Advertising — Official Website

موقع تعريفي احترافي ثنائي اللغة (عربي افتراضي / إنجليزي) لشركة **الرضا للدعاية والإعلان**.
مبني بـ HTML / CSS / JavaScript نقي — بدون أي إطار عمل أو خطوة بناء.

---

## ✨ المميزات

- **ثنائي اللغة بالكامل** — العربية هي اللغة الافتراضية (RTL) مع تبديل فوري للإنجليزية (LTR) بزر واحد، والاختيار محفوظ في المتصفح.
- **خط Tajawal** للعربية و **Manrope** للإنجليزية.
- **أنيميشن قوي**: شاشة تحميل، مؤشر تقدّم القراءة، مؤشر ماوس مخصص، ظهور العناصر عند التمرير، عدّادات أرقام، شبكة جزيئات متحركة في الهيرو، تأثير الضوء على الكروت، وشريط متحرك.
- **5 صفحات**: الرئيسية · من نحن · الخدمات · أعمالنا · تواصل معنا.
- **4 أعمدة خدمات**: التصميم · الطباعة · الويب · **الأنظمة المحاسبية والضريبية**.
- **نموذج طلب خدمة** يرسل البيانات مباشرة إلى واتساب برسالة منسّقة.
- **معرض أعمال** بفلاتر وLightbox.
- **جاهز للسيو**: Meta tags، Open Graph، Schema.org (ProfessionalService)، `sitemap.xml`، `robots.txt`.
- **متجاوب بالكامل** على كل المقاسات، ويدعم `prefers-reduced-motion`.

## 🚀 التشغيل محليًا

الموقع ملفات ثابتة — يكفي فتح `index.html` في المتصفح.
ولتشغيله عبر سيرفر محلي (مستحسن):

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## 🌍 النشر

### Vercel (موصى به)
1. ارفع المشروع على GitHub.
2. من [vercel.com](https://vercel.com) اختر **Add New → Project** واربط المستودع.
3. اترك كل الإعدادات كما هي (Framework: **Other**، Build Command: فارغ، Output: `.`).
4. اضغط **Deploy** — وكل `git push` بعدها ينشر تلقائيًا.

### Netlify
اربط المستودع من [netlify.com](https://netlify.com) — ملف `netlify.toml` جاهز.

### ربط الدومين
من لوحة تحكم Vercel/Netlify → **Domains** → أضف `elreda-ads.com`، ثم عدّل سجلات DNS كما تطلب المنصة.

## ✏️ كيف تعدّل المحتوى

### 1. تعديل أي نص (عربي أو إنجليزي)
كل النصوص موجودة في ملف واحد: **`assets/js/i18n.js`**
ابحث عن المفتاح وعدّل القيمة في القسم `ar` و/أو `en`:

```js
"hero.title2":"في النجاح",   // القسم العربي
"hero.title2":"In Success",  // القسم الإنجليزي
```

> ⚠️ أي مفتاح تضيفه في `ar` أضِف مقابله في `en` حتى لا يظهر المفتاح كنص خام.

### 2. تعديل رقم الواتساب
في `assets/js/main.js` أول السطور:
```js
var WA_NUMBER = '201050020785';
```
وكذلك في روابط `wa.me` داخل ملفات HTML.

### 3. إضافة عمل جديد للمعرض
- ضع الصورة في `assets/img/work/` (نسخة كبيرة + نسخة `-thumb`).
- انسخ بلوك `<article class="work">` في `portfolio.html` وعدّل `data-full` و`src`.
- أضف مفاتيح العنوان والتصنيف في `i18n.js`.

### 4. تعديل الألوان
كل الألوان في أول `assets/css/style.css` تحت `:root`.
